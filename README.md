# med-modules · 医学图像分割「即插即用模块」复现合集

> 看得懂、抄得走、插得上。

收录 **CVPR / ICCV / ECCV / NeurIPS 等顶会** 医学图像分割常用的**即插即用模块**：每篇一个文件夹，含
**架构图（截自论文原文）+ PyTorch 复现代码（逐行中文注释）+ 讲解文档 + 插入示例**。

> 说明：本合集以**顶会正式录用**论文为主；个别条目若为预印本会据实标注，不作为收录模板。
